# -Implementaci-n-_del_modelo_CNN_para_reconocimiento_de_im-genes
Este proyecto implementa un modelo de Red Neuronal Convolutiva (CNN) para la clasificación de dígitos manuscritos (0-9) utilizando el dataset MNIST en su versión simplificada (8x8 píxeles). El objetivo es demostrar la aplicación de técnicas de Deep Learning y la optimización de modelos para obtener el máximo rendimiento.
